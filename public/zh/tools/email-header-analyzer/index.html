邮件头分析器 — 在线分析原始邮件头

接收邮件并检查原始邮件头、SPF、DKIM、DMARC、发件人、链接和附件警告。

更新于 2026-08-17

GetOpenInbox 可以在线分析临时收件箱收到的邮件，显示 RFC 5322 原始源码、SPF、DKIM、DMARC，以及常见的发件人、链接和附件名称警告。

使用方法

  1. 打开临时收件箱并复制生成的地址。
  2. 把测试邮件发送到该地址。
  3. 邮件出现后打开它。
  4. 查看认证和风险部分。
  5. 打开原始源码，检查投递邮件头和 MIME 结构。

报告范围

分析器会检查发件人域名不一致、短链接、IP 地址链接、Punycode 域名和可能危险的附件名称。它不接受任意粘贴的邮件头，不扫描邮箱账户，也不测试 SMTP 端口。自动分析只能解释常见信号，不能保证邮件安全。
