# English content

Add Markdown files under `guides`, `comparisons`, `developers`, `tools`, or `pages`.

- Keep unfinished pages as `draft: true`; only `draft: false` pages are emitted into `public/`.
- Use lowercase kebab-case slugs.
- Keep descriptions accurate and under 180 characters.
- Use `faq` front matter only when the same questions and answers should be visible on the page.
- Use `related` with article slugs to add contextual internal links.

Run `npm run build` before previewing or deploying.
